# Study tools walkthrough: narration script (draft 2, 27 Oct 2026)

About 430 words, about 3 min. Voice: Kokoro `af_heart` at speed 1.0, the same voice as the HS2 podcast.
Footage is the live site, recorded by Playwright at 1920×1080; the edit is Remotion (captions, zooms, title cards).

Draft 2: plainer wording, and the HS2 answers claim corrected (nearly all hers, not all). Approved 27 Oct, then one
fix while recording: HS2 has no Flashcards tab, so row 2 no longer says every exam has the same tabs.
`narration.json` is what is actually voiced; this table is the readable copy.

| # | On screen | Narration |
|---|---|---|
| 1 | Hub home; the "Coming up" list scrolls slowly | This is the BN2 study tools page. All three finals are here, soonest first. Pick the exam you're studying for. |
| 2 | Tap INP Final; zoom on its tab strip, then HS2's | Each exam has a few tabs. Write, Flashcards, Rep questions and Mock. HS2 has Listen instead of Flashcards. I'll go through each one. |
| 3 | HS2 Write page: the Today box, then a piece: key words highlighted, blanks typed, the ladder dots | Write is for the written questions. For HS2 and Pharm, these are the lecturer's own questions. Nearly all the answers are hers too, from her model answers and her revision sessions. The few that aren't are marked. You don't learn the whole answer word for word. You learn the key words that get the marks. First you read the answer. Then the key words get hidden, a few at a time. Then you type them from memory, and the page marks it. Get one right twice in a row and it's done for the day. Get it right three days in a row and you know it. The box at the top tells you how many to do each day to finish before the exam. |
| 4 | INP exam page, Write tab, then the short-answer trainer: read, fill the gaps, write it out | INP works a bit differently. The short answers are about four marks each, so they're most of the paper. The lecturers haven't given out practice ones, so these are written from the lecture slides. Read the model answer, fill in the gaps, then write the whole thing yourself. Aim for about a hundred and fifty words, and use full sentences if the question says discuss. Keep going until you get eighty percent. |
| 5 | Flashcards: the deck list, Study all decks, Show answer, Good | Flashcards are for everything else you need to remember. Revision slides, quiz questions without the options, abbreviations and short answers. Think of the answer, then tap Show answer. Then pick Again, Hard, Good or Easy. Be honest, because that decides when the card comes back. It gives you enough new cards each day to get through them all before the exam. |
| 6 | Rep: answer a multi-choice question, it marks green; Redo my misses | Rep questions is the multiple choice. The lecturers' own quiz questions come first. It marks each one as soon as you answer. Questions you haven't seen much come up first. Anything you get wrong goes into your misses, so you can redo just those. |
| 7 | Mock start screen; then HS2 Listen's track list | Mock is a full practice exam with a timer. Do one for each exam before the real thing, so you know how the time feels. For HS2, the Listen tab has every written case question read out, one track each, so you can study while you're out. |
| 8 | Back on the hub; a title card with the routine: Write · Flashcards · Rep · Mock | So each day, do your Write round first, then flashcards, then some Rep. Leave the mock until a few days before. Your progress is saved in your browser, so use the same device each time. Good luck. |
