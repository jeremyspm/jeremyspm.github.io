How this page works

  1. Pick your paper, then the thing you're stuck on. The tool marked “Start here” is the best place to begin. Anything under “Also helps” is worth a go after.
  2. Or just type. The search box knows everyday words like BP, obs, mg to mL, pedigree and abbreviations, plus every tool's name.
  3. The tools are free practice, built from our own course material: the lecturers' quizzes, slides, case studies and demo videos. A student made them, not MIT, so if a tool and Canvas ever disagree, Canvas wins.
  4. Dates were last checked on . Each one disappears by itself once it has passed. Check Canvas for times and rooms.
  5. Your progress is saved inside each tool, in this browser on this device.
For the admin: where this page's content lives

Everything on this page comes from three lists at the top of the script in index.html (repo jeremyspm.github.io, local github/hub): TOOLS (name, link, one line each), PAPERS (each paper's problems, and the tools for each; the first tool is “Start here”) and each problem's optional date. A dated problem without keep hides itself once its date has passed.

To add a tool: one TOOLS entry, then name it in a problem's tools list. Run node index.check.mjs before pushing. It fails on a tool nobody links to, a link to a tool that doesn't exist, a bad date, or a script that won't parse.
